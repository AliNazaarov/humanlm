    Checks on the rewrite

      Four checks on every rewrite

      A rewrite counts as fact-safe only when it passes all four. The same code scores FeatherLM and every baseline.

      1. G1

        Nothing invented

        No new number, name, quote or "said" attribution that was not in the draft.

      2. G2

        Nothing lost

        Every number survives exactly, and at least 90% of the names do.

      3. G3

        No AI tells

        Stock phrases, em dashes, "not X but Y" contrasts, emoji and exclamation marks stay inside the range we measured in human writing.

      4. G4

        Not gutted

        The rewrite stays between 0.7 and 1.3 times the length of the draft, so content is not quietly dropped.
